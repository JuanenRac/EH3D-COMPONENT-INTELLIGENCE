# EH3D-COMPONENT-INTELLIGENCE: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Merging an import into a database that already exists (update, add, never silently overwrite verified data) | The first import makes a new file and refuses to replace one; merging needs rules for what wins that the owner has not decided | the first imports have been used on real lists |
| More CSV columns (quantity, description, alternatives) and the files of other design programs | Only the six columns of `CSV_FORMAT.md` are fixed; other formats need sample files | the first version of the CSV has been used |
| Assistance by artificial intelligence | Version 1 is deliberately without it; the rule on unchecked substitutions stays | version 1 has been used |
| The link with the symbols and footprints of the design tool | The design tool has not published the model of a symbol or a footprint that a record can point to | the design tool publishes its library model |
| A task kind for the server | The server has no kind of task for a database yet | the server accepts tasks from the engines |
